# Project Rules & Persistent Instructions

## UI / Design Locking
- **AI Agent Floating Button**: The design for this button is strictly locked.
  - **Icon**: MUST use `MessageCircle` from `lucide-react`.
  - **Color**: Background color MUST be `#C8102E` (Primary Red).
  - **Tag**: A pill-shaped tag with the text "Talk to our AI Agent" MUST be visible to the left.
  - **Indicator**: A green online indicator (#00FF00) MUST be present at the top-right of the button.
  - **Constraint**: DO NOT change this icon, color, or layout in future iterations unless explicitly requested by the user with reference to this rule.
